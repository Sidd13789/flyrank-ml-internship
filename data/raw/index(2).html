Abstract

This project investigates whether historical SEO and engagement signals can prioritize content refresh actions. A Random Forest classifier was trained on the anonymized FlyRank ML Internship dataset. The model predicts trend_direction to support editorial prioritization. Results indicate historical performance signals contain useful predictive information. The system is intended as a decision-support tool rather than automated decision making.

Introduction

The objective is to identify pages that should be refreshed, monitored, or maintained using historical search-performance signals. Recommendations are intended to assist human reviewers.

Data

  • Dataset: FlyRank ML Internship anonymized production dataset
  • Records: 30,000
  • Features: 44
  • No client names, URLs, domains, or private queries were used.

Methodology

  • Model: Random Forest Classifier
  • Target: trend_direction
  • Removed identifier columns and potential leakage feature trend_pct.
  • Handled missing values and encoded categorical features.
  • 80/20 train-test split.
  • Evaluation Metric: Accuracy.

Results

The Random Forest model outperformed the baseline on the evaluation split. Results should be interpreted as observed relationships rather than causal conclusions.

Limitations

  • Based on historical anonymized data.
  • Does not prove future Google search performance.
  • Supports human decision-making only.
  • Further grouped/time-aware validation is recommended.

Ranked Recommendations

  1. Refresh outdated content.
  2. Improve click-through rate.
  3. Increase user engagement.
  4. Monitor stable content.
  5. No immediate action for well-performing content.
